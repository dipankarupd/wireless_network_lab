# Diagrams

| Image | Generated by | Used in |
|---|---|---|
| `msc_ideal_path.png` | `msc_diagram.py` | Checkpoint 1: message sequence diagram of the ideal path |
| `fsm_initiator.png`, `fsm_responder.png` | `fsm_diagrams.py` | Checkpoint 2: the two state machines |

Regenerate after changing the protocol:

```sh
python3 msc_diagram.py .        # prints the image height, e.g. "height 1905"
swift svg2png.swift msc_ideal_path.svg msc_ideal_path.png 1800 1905

python3 fsm_diagrams.py .
swift svg2png.swift fsm_initiator.svg fsm_initiator.png 1800 1330
swift svg2png.swift fsm_responder.svg fsm_responder.png 1900 1440
```

The `.svg` files scale without loss, which is handy for slides.
