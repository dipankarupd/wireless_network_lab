# TTM4138 Wireless Security

This repository contains the materials used in the TTM4138 Wireless Security lab. A more comprehensive README can be found in [ESP_main_lab](ESP_main_lab).

## Repository layout

```text
.
├─ ESP_main_lab/                    # ESP32 workspace used for programming exercises in sessions 1–9
│  ...
├─ Jammer/                          # Workspace used for session 10
│  ...
├─ Prosim/                          # Libraries for running the protocol simulator locally
│  ...
└─ Session8_Capture/                # PCAP file required for session 8
   └─ Session_8_pcap.pcapng
```
